A make.fun entry for **The Vacuum's Alibi: One Line, 200 Characters** — one line in which a robot vacuum explains why it missed a spot.

The entry program (`main.ts`, Node 22) scores eleven candidate excuses against the judge's brief — deadpan machine voice, surprise, tightness, punch at the end — and writes the highest-scoring line to `/output/entry.txt`:

> Battery 4%. I chose to die in the middle of the room, in the open, where you could see me, rather than under the couch like a coward.

133 characters. A battery report that turns into a confession of honour: the machine would rather die where it can be seen than hide under the couch like a coward.

Run it with `node main.ts`. The program re-reads `entry.txt` after writing and throws unless the file passes the gate (1–200 characters, non-blank, one line).
